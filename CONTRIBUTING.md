# Contributing to Awesome AI Filmmaking

Thank you for contributing! This project exists because of people like you.

---

## How to Add a Tool (5 Minutes, No Coding Needed)

### Option 1 — Edit Directly on GitHub (Easiest)

1. Go to [README.md](README.md)
2. Click the pencil icon (top right of the file)
3. Add your tool to the correct category table
4. Scroll down and click **"Propose changes"**
5. Click **"Create pull request"**
6. Done!

### Option 2 — Fork and Clone

```bash
# Fork this repo on GitHub first

git clone https://github.com/YOUR_USERNAME/awesome-ai-filmmaking.git
cd awesome-ai-filmmaking

git checkout -b add/tool-name

# Edit README.md and add your tool

git add README.md
git commit -m "Add: Tool Name to Category"
git push origin add/tool-name

# Open a Pull Request on GitHub
```

## Tool Entry Format

```markdown
| Tool Name | Short description of what it does | Free/Paid/Freemium | [Site](https://link.com/) |
```

### Pricing Labels:
- `Free` — Completely free, no credit card
- `Freemium` — Free tier available, paid plans exist
- `Paid` — Paid only

---

## Checklist Before Submitting

- [ ] Tool is related to filmmaking, VFX, or content creation
- [ ] Link works and goes to the official site
- [ ] Description is short and clear (under 80 characters)
- [ ] Added to the correct category
- [ ] Not a duplicate of an existing entry
- [ ] Tool is legitimate and publicly accessible

---

## Adding a New Category

If your tool does not fit any existing category:

1. Add a new `##` section in README.md
2. Add it to the Table of Contents
3. Use the same table format
4. Explain in your PR why a new category is needed

---

## Reporting Issues

Found a broken link or outdated tool?

1. Go to [Issues](https://github.com/pawapawa007/awesome-ai-filmmaking/issues)
2. Click **"New Issue"**
3. Choose the **"Broken Link"** template
